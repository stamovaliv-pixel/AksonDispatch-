# AksonDispatch v1.0.3

Визуальный и навигационный патч поверх v1.0.2.

## Изменения
- Убрана цветная заливка фонов пиктограмм основных и резервных слотов; цвет пиктограмм сохранён для различения типов.
- Красная рамка выбранной даты теперь рисуется поверх верхней статусной полосы.
- Красный индикатор количества уменьшен примерно на 10%; порядок наложения календарных ячеек задан по индексу, чтобы соседние дни не перекрывали индикатор.
- Дата в календарной ячейке отображается как ДД.ММ в левом верхнем углу; чекбокс выгрузки появляется по кнопке инструментов и находится справа ниже зоны индикатора.
- Выбранная вкладка сохраняется в sessionStorage текущей вкладки браузера. Повторная загрузка профиля после обновления токена больше не сбрасывает раздел на «Обзор».
- «Совпадений» заменено на «Найдено», счётчик выровнен с фильтрами.
- Подпись «заявок» в счётчике правой панели приподнята.
- В статистике обзора подпись «Отменены» заменена на «Отменено».
- Удалены указанные подсказки над статистикой и календарём; календарная сетка поднята.
- Вместо старой легенды добавлены две подписи с пиктограммами: основные слоты — направление в РЦ; резервные слоты — другие адреса.
- Прошедшие дни календаря притушены для всех ролей, при этом индикатор числа заявок остаётся ярким и читаемым.

## Установка
Заменить `src/App.tsx`, `src/style.css` и `package.json` файлами из архива. SQL-миграция не требуется.
