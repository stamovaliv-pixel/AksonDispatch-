# AksonDispatch v1.0.5 — patch notes

## Изменения

1. Боковая навигация на широких экранах уменьшена до 203 px. Её правая граница выровнена с вертикальным разделителем между логотипом «Аксон Логистика» и названием «Аксон Диспетчерская» в шапке. Основная рабочая область автоматически расширяется на освободившуюся ширину. Мобильное выдвижное меню сохранено.
2. Индикаторы основных и резервных слотов в ячейке календаря расположены ближе друг к другу. Числовые значения отображаются обычным начертанием, не жирным; цвет пиктограмм сохранён (синий/зелёный).
3. В карточке существующей заявки добавлены кнопки копирования для адреса отправления, адреса назначения, номера задания на перевозку и комментария. Кнопки доступны только при наличии значения; после успешного копирования пиктограмма временно меняется на галочку.
