# AksonDispatch v1.0.7 — календарь и фильтрация

## Изменения

1. Календарь теперь отображает полные календарные недели с понедельника по воскресенье. По умолчанию показ включает текущую дату и следующие 29 дней; предыдущие дни текущей недели и хвост последней недели остаются видимыми, но приглушены. Переключатель предыдущих 30 дней расширяет ту же сетку назад, сохраняя полные недели — по принципу DockSlot.
2. Для прошедших дат и дат за пределами 30-дневного окна приглушаются верхняя дата и показатели слотов. Красный счётчик заявок остаётся читаемым. Создание новых заявок за пределами активного 30-дневного окна не предлагается.
3. При активном фильтре красный счётчик в каждой календарной ячейке считает только найденные активные заявки этой даты. Синие основные и зелёные резервные показатели свободных мест также рассчитываются только по найденным заявкам. Без фильтра сохраняется отображение общей занятости дня.
4. На датах с заявками показатели основных и резервных слотов снова используют синий и зелёный цвета соответственно; вокруг индикаторов добавлена тонкая рамка. На датах без заявок индикаторы остаются нейтрально-серыми. Поддержаны светлая и тёмная темы.
5. В карточке заявки справа от календаря увеличен шрифт даты до размера кода БЕ в строке маршрута.

## Файлы

- `src/App.tsx` — диапазон календаря, подсчёт совпадений по датам и дата в карточке заявки.
- `src/style.css` — приглушение прошлых/внеоконных дат и цвета/рамки индикаторов слотов.
- `package.json` — версия 1.0.7.

SQL-миграции не требуются.
