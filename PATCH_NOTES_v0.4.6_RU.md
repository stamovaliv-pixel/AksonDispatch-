# AksonDispatch v0.4.6 — скачивание вложенного реестра

## Что исправлено
- В таблице «Заявки» рядом с открытием заявки показывается отдельная кнопка скачивания, если к заявке прикреплён реестр.
- В правой панели выбранного дня календаря добавлена такая же кнопка.
- В карточке заявки сохранена кнопка «Скачать».
- Заказчик видит и скачивает вложение только у собственных заявок.
- Диспетчер, УТЗ и администратор могут скачивать реестры по всем заявкам.
- Скачивание выполняется через краткоживущую подписанную ссылку из закрытого bucket `dispatch-files`; публичный доступ не включается.

## Причина
Ранее скачивание было спрятано внутри модального окна заявки, а в таблице заявок и в правой панели календаря отдельного действия не было. Кроме того, политика Storage заменена на явное правило чтения для всех четырёх ролей с ограничением заказчика его собственными заявками.

## Обновление
1. Выполнить `0009_request_registry_download_access.sql` в Supabase SQL Editor.
2. Опубликовать фронтенд из архива через GitHub / RelaxDev / Vercel.
3. Повторно выполнять миграции 0001–0008 не требуется.

## Проверка
Проверены изменения TSX на структурные несоответствия и целостность архива. Полный `npm run build` требует установки npm-зависимостей и должен быть подтверждён в среде деплоя.
