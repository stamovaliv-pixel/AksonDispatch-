# AksonDispatch v1.0.2 — визуальная корректировка календаря

## Что изменено
- Сетка календаря приведена к стилистике Akson DockSlot: компактные ячейки, центральная дата, верхняя статусная полоса, красный счётчик в правом верхнем углу с выступом за границу ячейки.
- Чекбоксы выбора дат для выгрузки появляются только после включения «Инструменты выгрузки». Активная кнопка подсвечивается мигающим красным свечением.
- Карточки заявок справа уплотнены; кнопка просмотра закреплена в правом верхнем углу карточки.
- Переключатель показа отменённых заявок заменён на иконку с приглушённым состоянием выключено и красным свечением включено.
- Экспорт CSV стал иконкой и перенесён в верхнюю правую часть блока фильтров на странице «Заявки».
- Убрана строка навигации «АКСОН ЛОГИСТИКА / Раздел» со всех страниц; основной контент поднят выше.
- Цвет резервных слотов заменён с фиолетового на зелёный в светлой и тёмной темах.

## Файлы патча
- `src/App.tsx`
- `src/style.css`
- `package.json`

## Установка
Заменить файлы по тем же путям в GitHub и выполнить Redeploy. SQL-миграции не требуются: версия меняет только UI/разметку и номер пакета.

## Основа визуального решения
Стили календарной ячейки и красного индикатора адаптированы из `app/admin_calendar.html` проекта Akson DockSlot.
