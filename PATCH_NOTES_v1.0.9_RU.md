# AksonDispatch v1.0.9 — инструкции по ролям

## Изменения
- Добавлен раздел «Инструкция» в боковую навигацию для всех ролей.
- Заказчик видит только руководство заказчика.
- Диспетчер видит только руководство диспетчера.
- УТЗ видит только руководство УТЗ.
- Администратор видит все четыре инструкции: заказчика, диспетчера, УТЗ и администратора.
- Ограничение применяется при формировании содержимого страницы, а также в списке разрешённых страниц роли; чужие инструкции не выводятся обычным пользователям.
- Добавлены адаптивное оформление и поддержка светлой/тёмной темы.

## Установка
Заменить `src/App.tsx`, `src/style.css` и `package.json` в соответствующих путях GitHub. SQL-миграция не требуется. После загрузки файлов выполнить Redeploy в Vercel.

## Проверка
Проверена структура JSX/TSX через TypeScript transpile. Полная сборка проекта не выполнялась: в рабочей копии отсутствуют npm-зависимости (React, lucide-react, Supabase и XLSX).
